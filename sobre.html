Sobre o projeto

Nome do projeto

EduControl - Sistema de Cadastro de Alunos.

Objetivo

Desenvolver um pequeno sistema para organizar os dados dos alunos, permitindo cadastrar, consultar, alterar e excluir registros. O projeto também tem como objetivo praticar o desenvolvimento web e utilizar o Git e o GitHub para registrar a evolução do sistema.

Tecnologias utilizadas

HTML5

Estrutura das páginas.

CSS3

Estilização e organização visual.

JavaScript

Validação e funcionalidades do sistema.

Git e GitHub

Versionamento e armazenamento do código.

Funcionalidades

  • Cadastro de alunos.
  • Consulta e pesquisa de registros.
  • Alteração dos dados cadastrados.
  • Exclusão de alunos.
  • Armazenamento local no navegador.
